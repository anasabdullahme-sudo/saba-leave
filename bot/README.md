# بوت واتساب عيادات سابا

يرسل **طلبات التعديل** للمرضى على واتساب، تلقائياً، أول ما الموظف يضغط «طلب تعديل من المريض» في لوحة الموظفين.

## التشغيل على Railway (مرة وحدة)

### ١. مفتاح Firebase للبوت
1. Firebase ← مشروع **saba-leave** ← ⚙ **Project settings** ← تبويب **Service accounts**.
2. اضغط **Generate new private key** ← ينزل ملف `.json`.
3. **هذا الملف سري جداً** — لا ترسله لأحد ولا ترفعه في GitHub.

### ٢. Railway
1. ادخل https://railway.com ← **Login with GitHub**.
2. **New Project** ← **Deploy from GitHub repo** ← اختر **saba-leave**.
3. افتح الخدمة ← **Settings**:
   - **Root Directory**: `/bot`
   - **Watch Paths**: `/bot/**` (عشان البوت ما يعيد التشغيل مع كل تعديل في الموقع)
4. تبويب **Variables** ← **New Variable**:
   - الاسم: `FIREBASE_SERVICE_ACCOUNT`
   - القيمة: افتح ملف المفتاح بالـ Notepad، انسخ **كل** محتواه، والصقه.
5. أضف قرص دائم (عشان ما تعيد ربط الواتساب كل مرة): على لوحة المشروع اضغط **+ New** ← **Volume** ← اربطه بالخدمة، و **Mount path**: `/data`
6. الاشتراك: **Settings ← Plans ← Hobby**.
7. **Deploy**.

### ٣. ربط رقم الواتساب
1. افتح لوحة الموظفين بحسابك (المسؤول) ← اضغط زر **واتساب** فوق.
2. يطلع باركود ← من جوال **رقم البوت**: واتساب ← **الأجهزة المرتبطة** ← **ربط جهاز** ← امسح الباركود.
3. الزر يصير أخضر «واتساب متصل» ✓

## ملاحظات
- استخدم **رقم مخصص للبوت**، مو رقم الاستقبال الأساسي.
- البوت يرسل بفاصل ثواني بين كل رسالة، ويرسل فقط للمرضى اللي الموظفين طلبوا منهم تعديل.
- لو البوت طاح أو انفك الربط، الموظفين يطلع لهم زر يرسلون منه بأنفسهم — ما يتوقف الشغل.
- **فك الربط**: لوحة الموظفين ← واتساب ← «فك الربط» (للمسؤول فقط).
- السجلات (Logs) في Railway تبيّن كل رسالة انرسلت أو فشلت.
